# 社群分享文草稿

上次說把家裡的 TCL 老電視重新整理，現在程式碼公開了 🙌

週末參考 CleanYourTV，停用多數沒在用的服務跟 App，順手又加了：

1／YouTube、Netflix 看電視時間管理
2／兒童、爸媽模式切換，大人看不扣小孩額度
3／手機就能操作的雲端管理頁，家中不用常備電腦當主機
4／自己調整構圖、製作桌布的小工具

中間改了幾版，也踩了 TCL 背景程序被清掉、待機跟重開機的坑，這些紀錄一起留下來，給想自己改、或想丟給 AI 接手的人參考。

目前是在 TCL 55P715 上實作，需要自行設定，不是一鍵安裝版。家裡的照片跟真實帳號、金鑰都沒放上去。

https://github.com/qmolin-design/CleanYourTCL
