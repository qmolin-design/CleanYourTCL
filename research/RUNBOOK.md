# TCL 55P715 實機操作步驟（Owner 版）

分工：**你**＝在電視前用遙控器操作、看結果；**Opus**＝在 Mac 上下指令。每個階段開始前你說「開始」。
電視選單名稱可能和這裡略有不同，找不到就拍照傳給我。

## 階段 A：準備（約 10 分鐘，只做一次）

**A1 電視：打開開發人員選項**
1. 遙控器按「設定」（齒輪），或首頁右上角齒輪圖示。
2. 進入「裝置偏好設定」→「關於」。
3. 往下找到「版本」（Build），對它連按 OK 鍵 7 次，直到出現「你現在已是開發人員」。
4. 按返回回到「裝置偏好設定」，最下面會多出「開發人員選項」→ 進去 →「USB 偵錯」打開 → 確認。
   有「網路偵錯」或「ADB over network」開關的話也打開。

**A2 電視：查 IP**
設定 →「網路與網際網路」→ 點目前連線的 Wi-Fi 名稱 → 記下「IP 位址」（例如 192.0.2.23），傳給我。

**A3 Mac：安裝 adb（Opus 做）**
`brew install --cask android-platform-tools`（Google 官方工具）。

**A4 第一次連線（你看電視、Opus 下指令）**
1. Opus 執行連線。
2. 電視跳出「要允許 USB 偵錯嗎？」→ 用遙控器勾選「一律允許這部電腦」→ 按「允許」。
3. 沒跳視窗或連不上：拍下「開發人員選項」整頁給我。

## 階段 B：唯讀健檢（不改任何設定）

**B1 剛開機量測**
1. 設定 → 裝置偏好設定 → 關於 →「重新啟動」（或長按電源鍵選重新啟動）。
2. 開機後放著 2 分鐘不要操作，跟我說「好了」，Opus 量測約 1 分鐘。

**B2 碼錶（各量 3 次，記秒數）**
- 按 Home → 首頁可以移動選擇
- 首頁點 YouTube → 可以選影片
- 首頁點 Netflix → 可以選影片

**B3 五個 App 現況**
YouTube、Netflix、Disney+、四季線上、HBO Max 各打開播 10 秒，記「可播／不行」。
HBO Max 沒裝：到 Play 商店搜尋「Max」，拍下顯示的畫面。

**B4 使用 2 小時後量測**
平常看一段時間（約 2 小時）後跟我說，Opus 再量一次。

產出：健檢報告＋本機套件清單＋第一批停用名單（給你確認後才動）。

## 階段 C：YouTube 鎖定測試（約 30 分鐘，你在電視前；時間管理若不等小主機才做）

Opus 先停用 YouTube，你依序測並回報「打得開／打不開」：
1. 首頁點 YouTube 圖示
2. 遙控器 YouTube 鍵
3. 遙控器語音鍵說「YouTube」
4. iPhone 的 YouTube App 按投放圖示，選這台電視
5. 設定 → 應用程式 → 找 YouTube：有沒有「啟用」按鈕（有的話按下去看看，Opus 會再停回去）
6. Netflix、四季線上、Disney+ 各播 10 秒
7. 重開電視後再點一次 YouTube
8. 播放中關閉測試：Opus 先恢復 YouTube，你播任一影片，Opus 下關閉指令，看畫面是否立刻停止

測完 Opus 把 YouTube 恢復原狀，你確認 YouTube 能正常播放。

## 階段 D：瘦身第一批（每批約 15 分鐘，你在電視前）

1. Opus 給你這批 3～5 個套件的名稱與用途，你同意才動。
2. Opus 記錄原始狀態 → 停用 → 重開電視。
3. 你照下表逐項打勾：
   - [ ] 五個 App（原本可播的）各播 10 秒
   - [ ] HDMI 訊號源切換正常
   - [ ] 遙控器：Home、返回、音量、訊號源、YouTube 鍵、Netflix 鍵
   - [ ] 設定 → Wi-Fi 頁面打得開
   - [ ] Play 商店打得開
   - [ ] 首頁正常顯示（拍照）
4. Opus 量數值、你再量一次 B2 碼錶。
5. 全部打勾 → 下一批；任一項失敗 → Opus 立刻還原這批並停止。

## 階段 E：換桌面 Projectivy（可選，第一批做完後）

1. 從 Play 商店安裝 Projectivy Launcher。
2. 依畫面設定 override 模式，首頁只放五個影音 App。
3. 重開電視、做一次階段 D 的打勾表。
4. 不喜歡：解除安裝即恢復原廠首頁。

## 隨時適用

出現開不了機、遙控器沒反應、HDMI 沒畫面、Netflix 播放錯誤 → 立刻告訴我，Opus 還原最後一步；連不上就停手，不要恢復原廠設定。
